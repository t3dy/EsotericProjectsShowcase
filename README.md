# Esoteric Projects Showcase

**[https://t3dy.github.io/EsotericProjectsShowcase/](https://t3dy.github.io/EsotericProjectsShowcase/)**

---

A single-page index of digital humanities databases, image processing tools, and games built around esoteric, alchemical, and occult scholarship.

## Projects

### Knowledge Portals

| Project | Description | Status |
|---------|-------------|--------|
| [AtalantaClaudiens](https://t3dy.github.io/AtalantaClaudiens) | Site on Michael Maier's *Atalanta Fugiens* (1618) — 50 emblems, alchemical dictionary, source map, reception timeline, bibliography | Live |
| [TheosophicalAlchemyDB](https://t3dy.github.io/TheosophicalAlchemyDB/) | Rosicrucian and theosophical-alchemical traditions (16th–18th c.) — 206 entities, interactive map, essay pages | Live |
| [MedievalMagicDB](https://t3dy.github.io/MedievalMagicDB/) | Medieval magic — ritual practice, astral image magic, necromancy, grimoires, manuscript transmission | Live |
| [Renaissance Magic DB](https://t3dy.github.io/RMDB/) | Renaissance magic — 29 figures, 337 documents, 139 terms, 58 timeline events, 9 traditions | Live |
| [WitchcraftStudiesDB](https://t3dy.github.io/WitchcraftStudiesDB/) | Historical witchcraft studies (Clark, Hutton, Ginzburg) — 320+ entities, trials, demonology, locations | Live |
| [CrowleyDB](https://t3dy.github.io/CrowleyDB/) | Aleister Crowley research database — corpus catalog, Tree of Life correspondences, timeline, initiation game | Live |

### Tools & Image Pipelines

| Project | Description | Status |

| [Goetia Sigil Analysis](https://t3dy.github.io/goetia-sigil-analysis/) | Image processing pipeline for Goetia sigils — Zhang-Suen skeletonization, Hough transform, geometric pattern extraction | Live |

### Games & Experiments

| Project | Description | Status |

| [Almagest / Digby Game](https://github.com/t3dy/digby-game) | Construction kit for historical RPG scenarios from scholarly sources — first dataset: Kenelm Digby (1628) | Desktop |

## Structure

The showcase is a single static HTML file (`index.html`) with no dependencies or build step. Hosted on GitHub Pages from the `master` branch.

To update: edit `index.html` and push. Pages redeploys automatically.
